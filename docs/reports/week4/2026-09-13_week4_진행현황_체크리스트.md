## 실제 인프라 E2E 검증 절차 (미실시)

```bash
docker compose up -d rabbitmq redis
```

1. RabbitMQ management UI(http://localhost:15672)에서 `deploy.exchange` / `deploy.queue` 자동 생성 확인
2. 백엔드 기동 → 배포 요청(`POST /api/projects/{id}/deployments`) → 202
3. 로그 순서: `published deploy request` → `received deploy request` → 파이프라인 단계 로그
4. 같은 프로젝트 재요청 → **409** (`DEPLOYMENT_ALREADY_IN_PROGRESS`), Redis 에 `deploy:lock:project:{id}` 존재 확인
5. SSE: `GET /api/deployments/{id}/logs/stream?access_token=<토큰>` → `log`/`status` 이벤트, 종착 시 `close`
6. 종착 후 Redis 락이 사라졌는지 확인
7. 환경변수 등록 후 배포 → 컨테이너에 주입됐는지 `docker inspect` 로 확인

> ⚠️ 현재 다른 프로젝트 컨테이너(`weekly-report-backend`)가 호스트 **8081** 을 점유 중이다.
> traefik 이 같은 포트를 쓰므로 compose 기동 전에 정리가 필요하다.
